# 单域名部署说明

域名：**http://hair.cnmc-clm.com.cn**（解析到内网固定 IP）

前后端共用同一域名，通过**路径**区分，无需二级域名。

## 访问地址一览

| 用途 | 地址 | 说明 |
|------|------|------|
| **移动端 H5**（员工预约） | http://hair.cnmc-clm.com.cn/m/login | 输入工号即可，可收藏此链接 |
| 移动端首页 | http://hair.cnmc-clm.com.cn/m/home | 登录后自动进入 |
| **PC 管理后台** | http://hair.cnmc-clm.com.cn/admin/login | 管理员 `admin / admin123` |
| 根路径 | http://hair.cnmc-clm.com.cn/ | 自动跳转移动端 |
| API 文档（运维） | http://hair.cnmc-clm.com.cn/docs | 可选，内网排查用 |
| 健康检查 | http://hair.cnmc-clm.com.cn/health | 运维监控 |

> 前端 axios 使用相对路径 `/api`，打包后无需写死后端 IP。

## 架构

```
浏览器
  │
  ▼
http://hair.cnmc-clm.com.cn  （IIS 或 Nginx :80）
  │
  ├─ /              → front/dist 静态文件（Vue 页面）
  ├─ /m/*           → 移动端 H5
  ├─ /admin/*       → PC 管理后台
  │
  └─ /api/*         → 反向代理 → FastAPI 127.0.0.1:8001
       /docs        → 反向代理 → API 文档
       /health      → 反向代理 → 健康检查
```

后端 **8001 端口仅本机监听**，不对公网开放；外网只访问 80 端口。

## 一、部署步骤概览

1. 将代码放到服务器（如 `D:\zmHair` 或 `/opt/zmHair`）
2. 初始化并启动后端（`back/start_prod.bat` 或 `back/start_prod.sh`）
3. 打包前端（`deploy/build.bat` 或 `deploy/build.sh`）
4. 配置 Web 服务器指向 `front/dist`
5. DNS 将 `hair.cnmc-clm.com.cn` 解析到服务器 IP
6. 浏览器访问验证

## 二、后端部署

### 1. 环境

- Python 3.10 或 3.11
- Windows：先运行 `back\start.sh` 或手动 `python -m venv venv` + `pip install -r requirements.txt`
- Linux：运行 `back/start.sh` 完成初始化

### 2. 生产配置

```bash
cd back
cp .env.example .env
```

编辑 `.env`：

```ini
APP_NAME=企业内部理发预约系统
SECRET_KEY=请改为随机长字符串
DATABASE_URL=sqlite:///./zmhair.db
HOST=127.0.0.1
PORT=8001
RELOAD=false
```

> **务必修改 SECRET_KEY**，否则 JWT 不安全。

### 3. 启动

**Windows**
```bat
cd back
start_prod.bat
```

**Linux**
```bash
cd back
chmod +x start_prod.sh
./start_prod.sh
```

验证：`curl http://127.0.0.1:8001/health` 应返回 `{"status":"ok",...}`

### 4. 开机自启（可选）

- **Windows**：用 NSSM 或任务计划程序注册 `start_prod.bat`
- **Linux**：编写 systemd unit，ExecStart 指向 `start_prod.sh`

数据库文件 `back/zmhair.db` 请定期备份。

## 四、Web 服务器配置

### 方案 A：Windows Server + IIS（推荐内网 Windows 环境）

#### 前置模块

1. **URL Rewrite**
2. **Application Request Routing (ARR)** → 启用 **Enable proxy**

#### 站点

1. IIS → 添加网站
   - 站点名称：`zmHair`
   - 物理路径：`front\dist` 的绝对路径
   - 绑定：主机名 `hair.cnmc-clm.com.cn`，端口 80
   - 应用程序池：**.NET CLR = 无托管代码**

2. 确认 `dist\web.config` 存在（打包时从 `front/public/web.config` 复制）

3. 若 API 端口不是 8001，修改 `front/public/web.config` 后重新打包

### 方案 B：Linux + Nginx

1. 修改 `deploy/nginx/hair.cnmc-clm.com.cn.conf` 中 `root` 为实际 dist 路径
2. 安装配置：

```bash
sudo cp deploy/nginx/hair.cnmc-clm.com.cn.conf /etc/nginx/conf.d/
sudo nginx -t
sudo systemctl reload nginx
```

3. 确保 DNS / hosts 将 `hair.cnmc-clm.com.cn` 指向本机

## 六、常见问题

**1. 页面能开，接口 502 / 404**

- 确认后端 `start_prod` 已运行
- 确认 IIS ARR 已启用 proxy，或 Nginx `proxy_pass` 地址正确

**2. 刷新 /admin/dashboard 出现 404**

- IIS：检查 `web.config` 中 SPA Fallback 规则
- Nginx：检查 `try_files $uri $uri/ /index.html;`

**3. 只想用 IP 访问**

- IIS/Nginx 绑定改为 IP，或增加 `server_name` / 主机头
- 访问路径不变：`http://IP/m/login`、`http://IP/admin/login`

**4. 后续上 HTTPS**

- 在 IIS / Nginx 配置 SSL 证书
- 前端无需改代码（相对路径 `/api`）
